Aplicativo Android

Este aplicativo consome uma API para buscar e exibir informações na tela de forma simples e organizada.
O usuário pode pesquisar e consultar os dados disponibilizados pela API, enquanto o aplicativo apresenta estados de carregamento, sucesso e erro.
O projeto utiliza Kotlin, Jetpack Compose, Retrofit, Coroutines e arquitetura MVVM, separando a interface, lógica e comunicação com a API.
Para executar, basta abrir o projeto no Android Studio, sincronizar as dependências e rodar em um emulador ou dispositivo Android.
